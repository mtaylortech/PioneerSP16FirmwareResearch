The MainWindow/label target conclusions combine **captured primary vtables with original-file slot cells**. Those live slot contents were not separately captured; only the saved widget/listener target-byte receipts establish loaded targets. The narrow registered-listener prediction is supported at the two boundaries. The older wording allowing no unresolved primary ancestor callback cannot be extended into universal touch absence. No-input snapshots also leave intervening changes and actual callback execution unobserved.

The accepted [logical ingress map] `../ghidra/parallel-send-round-20261009/input/HANDOFF.md` (evidence not published) gives `0x55603c → 0x55767c`, copying a 128-byte panel packet with byte0=1. Signed field packet+0x34 supplies encoder object implementation+0xe2c, ID3. Implementation+0xa8 determines whether the callback uses a raw incoming signed halfword or signed16(new−old), with old counter at +0x5c. `0x557d24 → 0x55ca30 → 0x55c354 → 0x55cb10` reaches an observer virtual +0x14 for nonzero delta. Actual observer registrations, active-view delivery and physical/emulator transport remain unproved; accepted ingress is not proof of dispatch to C.

At the footer, `0x2c004c` validates ID/count and calls `0x2bffb0`. Its ordinal-three component gate tests W flag bit1 then W+0xc8: saved flags `0x12` and enabled 1 satisfy that specific gate. The original primary controller +0x44 cell maps to this callback; its live slot was not sampled. Send handler `0x2df590` rejects mode 2 and a separate service predicate `0x2fdf7c`, which calls service virtual +0x90. **Widget enabled 1 does not prove that predicate.** The handler gets the current value, adds the delta, clamps against **C+0x80/+0x84**, then calls `0x2f60dc`. Those controller clamp words are unsampled.

For mode 0/step -1, original `0x2f60dc` selects its ordinary-channel branch: owner service `0x32b664`, channel virtual +0x10, interface virtual +0x30, then setter-request virtual +0x10 at `0x2f6144`, with requested value in r1 and r2=0. This is an original request boundary, not evidence that a delta executed, the request applied, asynchronous work completed or pixels changed. No conclusions beyond that boundary use the excluded async assignment.

**Next offline work:** trace the original panel read/poll producer into `0x55603c/0x55767c` and the encoder observer registration into the active footer callback. The accepted PanelMicon constructor opening `/dev/subucom_spi0.1` does not establish that bridge. Avoid invented panel packets, X11 key substitutions or a Send drag with no positive edit prediction. A later explicitly authorized diagnostic would still need loaded delivery owners, service+0x90 result and controller clamp fields before choosing an edit; no such run is authorized here.
