# Completion observer lifetime and the next UI decision

October 9, 2026 — America/Chicago. Review only; no experiment launched.

The cycle **replicated persistent drawing and validated the natural event queue/gate**, but did not answer where tagged input stops. Native observation completed **600.315s**, bounded_stop/exit 0, with verified cleanup. Original 800×480 HOME pixels are identical from **285.286–595.049s**, matching the previous frontier; resources remain **1,314**. New evidence is **472 matched XPending returns/gates**: ten positive results lead to ten natural XNextEvent returns, followed by 462 empty-queue results. The 429 assembled incoming packets establish socket activity, not tagged delivery. Completed startup, successful loading and input response remain unproved; no performance gain was measured. **The consequential failure was observer lifetime.** Hooks retired at **59.193s**, after the main asynchronous submission returned; resume-file accesses followed at **59.316/59.317s**. File results, worker completion and listener/state evidence are missing. The retirement message claims an observed listener path, but there is no listener receipt. This cannot establish an original loading failure. Withholding input was correct. The earlier missing-mapping failure and absent native final remain preserved; this clean retry does not erase them. README agrees with these limits. [Raw retirement/access records] `../experiments/persistent-home-input-retry-20261009/run-1/supervision/guest.stdout.txt` (evidence not published), [earlier failure] `../experiments/persistent-home-input-20261009/run-1/supervision/guest.stderr.txt` (evidence not published).

Retain the corrected fixture, scoped waits, cooperative main/select, guards and supervision. Reject retirement on submission return and a permanent-main-stall inference. Constructor/resource, Expose, queue-dispatch and painting discovery have left the critical path; keep sparse paint/persistence confirmation. The cycle added reliable event-service knowledge but did not advance startup or usability.
