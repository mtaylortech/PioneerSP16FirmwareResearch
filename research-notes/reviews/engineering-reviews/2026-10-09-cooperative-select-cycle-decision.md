# Cooperative select cycle: retain service, test timer expiry

Reviewed October 9, 2026, America/Chicago. No experiment launched. This assessment reuses the [latest HANDOFF] `../experiments/cooperative-select-20261008/HANDOFF.md` (evidence not published) and [detailed timer plan] `2026-10-09-timer-futex-next-test.md` (evidence not published).

**Result and knowledge.** The cycle asked whether cooperative select lets pending original redraw execute. Main completed 132 deferred selects, but painting was not observed. Beyond the previous matched redraw return, the original Expose now demonstrably preserves a clipped `(1,1,800,480)` rectangle and a nonempty covering dirty region. Unchanged collection count does not establish rejection. Resource returns remain 1,314. Neither painting site nor XPutImage fired; two exact drawable samples are black, not evidence of continuously black output. Completed startup and usable UI remain unproved; no input was sent. [Raw receipts] `../experiments/cooperative-select-20261008/run-1/supervision/guest.stdout.txt` (evidence not published), [pixels] `../experiments/cooperative-select-20261008/run-1/display-observations.json` (evidence not published).

The strongest next-decision evidence is named **Juce Timer** requesting a **90.506 ms relative FUTEX_WAIT**, then remaining deferred about **337.6 seconds** until stop. The installed handler discards this timeout and its manager waits unboundedly. Confidence in that emulator defect is high; its causal connection to painting remains moderate because the consumer/callback is only statically associated. [Final wait state] `../experiments/cooperative-select-20261008/run-1/cooperative-select-20261008-run-1-result.json` (evidence not published), [static path] `../experiments/cooperative-select-20261008/selected-deferred-service-static.json` (evidence not published).

**Failures and limits.** Native bounded stop now succeeds at 600.726 seconds probe elapsed, exit zero, with owned cleanup/postflight passing: harness completion, not application completion. Older missing finals remain unexplained failures. The initial synthetic control's missing `get_id` failed, was corrected, and all 13 controls passed. Unsupported UIThread priority-inheritance locking remains observed; subsequent thread state and UI causality are unresolved. The verifier omits actual `Juce Timer` from `relevant_waits`; raw/final records preserve it. The earlier review's unavailable external-review limitation is superseded by the corrected location in README. [Supervision] `../experiments/cooperative-select-20261008/run-1/attempt-supervision.json` (evidence not published), [retained control failure] `../experiments/cooperative-select-20261008/initial-control-failure.stderr.txt` (evidence not published), [controls] `../experiments/cooperative-select-20261008/controls.json` (evidence not published).

**Decision and efficiency.** Retain cooperative select; reject a duration-only repeat or bundled timing repairs. Expose delivery/clipping and completed constructor observations can retire. Correct the next working verifier's thread-name selection so its summary includes the decisive wait. Select counts and sampled durations demonstrate service, not controlled speedup; observer overhead is unmeasured. README already agrees with this frontier and next action, so stays unchanged.
