## Instruction-supported route

- The prior C+0xc → V+0x80 attachment remains a distinct view/widget listener relationship. It must not be reinterpreted as an attachment of C+8. Construction writes C's primary table `0x881dac` and C+8 table `0x881e4c`; `0x3273a4` stores V at C+0x138.
- `0x3273f8` calls `0x3288b8` with C and W+0x2c. The callee appends C to the manager's controller array (pointer/capacity/count at W+0x2c/+0x30/+0x34). It does not itself deliver input. See [registration export] `exports/registration-entries/003288b8.asm.txt` (evidence not published) and [raw lead] `logs/registration-windows/stdout.txt` (evidence not published).
- Manager construction `0x318c70` stores primary table `0x89f964`; its slot +8 (`0x89f96c`) points to `0x3198ec`, the original encoder-press receiver. In `0x31eb50`, r7=W and r6 is its supplied input manager. Calls at `0x31ecc8` through `0x31ed28` register W through `0x55e454` for indices 0–6. That helper selects input-manager+8's encoder array +0x1c under its +0x24 count, then calls encoder virtual +0x14 with r1=W. See [registration instructions] `logs/manager-registration-window/stdout.txt` (evidence not published), [input registration] `exports/encoder-source-entries/0055e454.asm.txt` (evidence not published).
- Concrete `UIRotaryEncoder` constructor `0x564190` installs table `0x92fa4c`. Its +0x14 entry is `0x563ff4`, which deduplicates/appends the observer to the encoder's +0x18/+0x1c/+0x20 roster. Its +8 entry is `0x563e08`, which returns encoder+8. RTTI and constructor writes establish this class contract; **complete binding of the supplied input-manager array to these concrete instances is still open**, so this is not a signature-only join. See [table/constructor window] `logs/concrete-encoder-methods/stdout.txt` (evidence not published), [observer registration] `exports/encoder-source-entries/00563ff4.asm.txt` (evidence not published), [getter] `exports/encoder-source-entries/00563e08.asm.txt` (evidence not published).
- `0x564330` keeps raw press state at encoder+0xe, optionally transforms it through encoder+0x10 virtual +0xc, compares the filtered state at +0xd, and returns without filtered-press emission when unchanged. When changed, it stores +0xd and calls each observer virtual +8 with **r0=observer, r1=encoder, r2=filtered boolean**. The separate raw-change observer call uses slot +0xc. See [press export] `exports/encoder-press-export/00564330.asm.txt` (evidence not published) and [corrected wrapper] `exports/encoder-wrapper-corrected-export/00564b24.asm.txt` (evidence not published).
- `0x3198ec` preserves the encoder/boolean. Its thread-identity comparison determines direct versus queued work. On the direct branch it calls `0x31908c`, which matches D+0x98 (D=W+0x24) to each registered controller's virtual +0x14 view getter. C's table entry `0x881dc0` is `0x27e0b0`, returning C+0x138=V. Hence the registered C can be selected when D's active view equals V; this does not assert that runtime state was observed. See [manager resolution] `exports/encoder-manager-entries/0031908c.asm.txt` (evidence not published).
- The selected controller's virtual +0x1c (`0x881dc8` → `0x2741c0`) returns its current popup if present, otherwise C. Only the no-current-popup case yields this C route. After validation, `0x319ad4` loads [C+8], `0x319adc` forms r0=C+8, `0x319ad8` restores r1=encoder, `0x319ae0` restores r2=boolean, and `0x319ae4`/`0x319ae8` dispatches virtual +8. Table word `0x881e54` targets `0x2740a8`, which subtracts 8 and branches to `0x2740b0`. This is the actual C+8 delivery relationship. See [delivery] `exports/encoder-manager-entries/003198ec.asm.txt` (evidence not published), [popup selection] `exports/encoder-manager-entries/002741c0.asm.txt` (evidence not published).
- `0x2740b0` requires a nonnull, aligned, sentinel-valid C+0x138 view; r2 must be nonzero; incoming encoder virtual +8 must return zero. It then gets the selected row through V virtual +0xe4 (`0x455018` → `0x778828`, selected-range ordinal zero) and forwards that row through C virtual +0x44 → `0x27db68` → `0x27da08`. Under the concrete encoder contract above the zero-return condition is encoder index zero. This activation uses the **current selected row**, not a hard-coded SAVE row. The Step 05d default-menu row 2 SAVE mapping remains conditional on selection.
