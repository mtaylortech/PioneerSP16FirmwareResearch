For an attempt named `LABEL`, `logs/LABEL-console.log` preserves stdout/stderr and `logs/LABEL-qiling.log` preserves the emulator trace unless a row gives another path. Explicit host return codes are principally available in the later `LABEL-supervision.json` files. Where no historical exit record exists, the exit code is **unavailable**, even if logs show an exception.
