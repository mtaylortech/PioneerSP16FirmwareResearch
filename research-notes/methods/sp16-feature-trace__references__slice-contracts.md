# Used layout and behavioral slices

Use this method only when a layout-backed observer/model claim matters to the selected question. Existing `trace_records.py` checks record structure and references; it does not check ARM32 accesses, alignment or behavioral effects. Reuse existing provenance as the offset authority. A resolved output is a derivative, not a second independently maintained manifest.

Declare selected release/hash, pointer width 4, little endianness and actual ARM/Thumb mode; receiver adjustment, complete object/subobject and construction/execution phase; offset/access width, pointer/scalar/unknown type and its support status; raw/ABI access, declared alignment/packing; supported extent or null/unknown; lifetime status and original locator. Check the actual observer/model consumer and original bytes/accesses separately: a nearby aligned pointer can pass layout mechanics while naming the wrong object. Do not infer C++ scalar types from access width, full allocation extent from a largest access, or lifetime from pointer/table equality.

`scripts/slice_contracts.py layout declaration.json` is a stdlib mechanical check. Numeric inputs are integers or unsigned decimal/hex strings; bools are rejected. Required keys are demonstrated in the [consumed example] `../../../../experiments/sp16-skill-contracts-20261011/results/owner-layout.json` (evidence not published). Missing/malformed/empty declarations, invalid widths, known-bound violations, undeclared overlaps and declared unpacked ABI misalignment are invalid. Unknown extent/type/lifetime or ABI alignment/packing yields partial; raw accesses and explicit packed layout may bypass ABI member alignment, never bounds or pointer width. Overlaps need an explicit shared group, kind (`union`, `subobject`, `construction-phase`) and reason; phase overlaps also need distinct phases. These declarations are analyst claims to review, not facts recovered by the helper. Partial exits zero, so inspect JSON status. No compiler layout or lifetime checker is provided.

Attach a small supported transition/coverage table: original site/version, receiver/incarnation, producer, input/precondition, result/callback or unknown, effects, one of the existing six evidence classes, falsifier and observed coverage. Distinguish request, admission, execution, result, outcome, unload/release and refresh. Caller deferral, failed/dropped work and unsupported routes need their own entries when relevant. CandidateLedger stays hypothetical. Bind observation completeness to the stated window/roster; count=2 with one retained member is one-member evidence. The frozen observer's early-retirement defect is a prerequisite in the [worked slice] `../../../../experiments/sp16-skill-contracts-20261011/HANDOFF.md` (evidence not published), not repaired or qualified by these checks.

Define expected events/results/effects from matching retained original receipts independently of model output. Static instructions can define a ready acceptance contract, but cannot create an observed golden. If the required original capture never occurred, keep original comparison `NOT-RUN`, identify capture/adapter/receiver and coverage prerequisites, and exercise synthetic comparator mechanics separately. Preserve raw captures and every projection rule; no silent event filtering or invented model effects.

`scripts/slice_contracts.py compare contract.json normalized-trace.json` checks exact event/result/effect maps, missing/extra events, context (version/hash/slice/receiver/adapters) and declared partial-order edges. Only declared timestamp/sequence keys can be incidental. Keep ownership, results and effects exact; justify required ordering from the original dependency, without imposing an arbitrary scheduler interleaving. The [callback contract] `../../../../experiments/sp16-skill-contracts-20261011/results/comparison-contract.json` (evidence not published) requires reader return before callback completion and both result/flag effects. Its synthetic projection uses emitted result plus actual final model state; it claims no intermediate store timing. The comparator trusts supplied provenance and slice completeness; independently verify these before making an original behavioral claim. Reject a deliberately missing/changed effect and event as meaningful controls. Required new helper invocations should have finite host supervision and retained stdout/stderr/cleanup within current authorization.

Both inputs require nonempty version/slice/receiver strings, a lowercase 64-hex SHA256, and an explicit adapter object. Empty adapter maps are valid; absent/null maps are invalid. Adapter values must be finite JSON data and match recursively, including keys, ordered arrays and scalar types: bool differs from number, and parsed integers differ from floats (`1` differs from `1.0`); same-type numeric values compare without coercion. Object key order is incidental. Missing, malformed or mismatched context returns rejected JSON and a nonzero comparison CLI exit. The [focused correction receipts] `../../../../experiments/sp16-skill-context-fix-20261011/HANDOFF.md` (evidence not published) retain the earlier false matches and controls; they do not supply original behavior evidence.
