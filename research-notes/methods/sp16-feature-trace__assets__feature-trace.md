# Feature trace: <feature>

## 1. Investigation and scope
ID/date (America/Chicago), objective, completion criteria, current authorization, stopping boundary and answered/partial/unresolved status.

## 2. Firmware and artifact identity
Internally supported release/version source; original and analysis paths, SHA-256, sizes. Missing/mismatched identity and availability limits.

## 3. Tools and environment
Actual versions, provider/profile, format/architecture/mode, loader/base/relocation/library/decompiler settings, environment substitutions. Link exact commands/configs.

## 4. Functions investigated
| Function ID/name provenance | Binary ID | Entry/address space/mode | Inclusive body ranges | Evidence/locator |
| --- | --- | --- | --- | --- |

## 5. Call and data relationships
Relevant caller/callee/field/table/interface edges, conditional paths, unresolved indirect calls and dependency sequence. Distinguish reference edges from value-flow proof.

## 6. Confirmed findings
Separate artifact observations, static support and actual runtime observations. Link each claim ID to source bytes/exports/log locators; state coverage.

## 7. Inferred behavior
Inputs/outputs, states, initialization order, dependencies, interfaces and errors where relevant. Give rationale, evidence, confidence and limits; label decompiler artifacts.

## 8. Hypotheses and unknowns
Competing explanations and missing joins; keep unresolved fields explicit.

## 9. Contradictions and unexpected results
Both evidence sides, retained failures, missing receipts and effects on conclusions. State none encountered if appropriate without implying an exhaustive search.

## 10. Validation actually performed
| Test ID | Procedure/config/evidence | Executed status | Actual result | Coverage/limits |
| --- | --- | --- | --- | --- |

Keep proposed/blocked tests separate. Exit status alone is insufficient.

## 11. Confidence and reproducibility
Per-claim and overall rationale; instructions and identities for replay, searched boundaries/reuse, unavailable dependencies and semantic/completeness limits. Link `trace.json`, raw evidence and query attempts.

## 12. Recommended next experiment
One highest-value discriminator, expected outcomes, required evidence and current permission/budget status. Recommendations are not execution receipts.
